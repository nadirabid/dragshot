# DragShot

Three finger snapshot anything to provide a reference to your agent.

![DragShot composer over macOS 27 Golden Gate](assets/dragshot-example.png)

## Install

Paste into a new chat:

```
Install DragShot by running this skill: https://raw.githubusercontent.com/nadirabid/dragshot/main/skills/install-dragshot/SKILL.md
```

## Privacy

DragShot collects zero data. No accounts, analytics, telemetry, API keys, or network code. Captures and settings stay on your Mac; DSH delivery, when enabled, uses an owner-only local socket. All DragShot processing is local, the app has no third-party dependencies, and the app plus bridge are under 4k lines.

The full audit and its limitations are in [development notes](DEVELOPMENT.md#privacy).
