# Lookit demo

The demo shows a fictional Forma dashboard: capture its button, send visual feedback to an existing DeepSeek Harness (DSH) session, then view the button DSH changed.

The screenshot, Lookit composer, DSH delivery, response, and file edit are real. A temporary recording adapter maps automated mouse input to Lookit's native capture flow because automation cannot synthesize the physical three-finger gesture. The installed production app was restored after recording.

The edit trims agent wait time, adds camera moves and captions, and composites the recorded app windows over a clean recording of the same desktop wallpaper. Personal windows, widgets, session lists, and the menu bar are excluded. No audio is recorded.

- `lookit-demo.mp4`: 15 seconds, 1920 × 1080, 30 fps.
- `lookit-demo.gif`: looping README preview, 1280 × 720, 18 fps.
