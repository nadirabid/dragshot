# Lookit demo

The demo shows two refinements to a fictional Forma dashboard in one continuous recording. DSH starts behind Chrome. A Lookit capture sends “Make this stand out more.” with the selected button, brings DSH forward automatically, and shows DSH processing the request. A second capture sends only “Make this punchier.” with the headline. DSH identifies the targets from the screenshots and chooses the styling changes; the prompts do not name the elements or prescribe colors, typography, or replacement copy.

The screenshots, Lookit composer, automatic DSH activation, processing, responses, and file edits are real. A temporary recording adapter maps automated mouse input to Lookit's native capture flow, interpolating each selection over 650 ms because automation cannot synthesize the physical three-finger gesture. The trackpad illustration is an instructional overlay, not footage of physical fingers. The installed production app and prior targeting preferences were restored after recording.

The edit uses one continuous source interval with a strictly increasing time map: no internal cuts, reordered events, replacement app frames, or desktop compositing. Smooth speed ramps tighten pauses and slow the brief typing moments; the video is labeled “Continuous take · speed adjusted.” Eased camera moves and captions guide attention. The recording includes only the demo apps and desktop wallpaper; personal windows, widgets, and session lists are excluded, and the menu bar is cropped out. No audio is recorded.
